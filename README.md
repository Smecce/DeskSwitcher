# 🖥️ DeskSwitcher

Небольшая WPF-панель для переключения виртуальных рабочих столов Windows: одна кнопка — один стол.

## Возможности

- Кнопка на каждый рабочий стол, текущий выделен
- Панель сама обновляется при создании, удалении и переименовании столов
- Окно видно на всех столах и сворачивается в трей
- Глобальные горячие клавиши

## Горячие клавиши

| Сочетание | Действие |
|---|---|
| `Ctrl` + `Alt` + `1`…`9` | Перейти на стол с этим номером |
| `Ctrl` + `Alt` + `←` / `→` | Перейти на соседний стол |

Крестик окна прячет программу в трей. Выйти можно через меню значка в трее.

## Требования

- Windows 10 (сборка 19041+) или Windows 11
- [.NET 10 SDK](https://dotnet.microsoft.com/download)
- Пакет [Slions.VirtualDesktop](https://www.nuget.org/packages/Slions.VirtualDesktop)

> Библиотека использует недокументированные интерфейсы Windows, поэтому поддерживаются только определённые сборки системы. Список — на странице пакета.

## Запуск

```bash
git clone https://github.com/Smecce/DeskSwitcher
cd DeskSwitcher
dotnet run --project DeskSwitcher
```
